PRODUCT MANAGER

Only a Supabase user ID explicitly added to public.admin_users can manage products or upload images.

Admin Sign In

Create the admin user in Supabase Dashboard → Authentication → Users. Then add that user's UUID to public.admin_users using the SQL in the README. This page has no public sign-up form.

Add a Product

Choose an image to upload it directly to the Supabase Storage bucket named product-images. Keep product images compressed when possible to save free storage and bandwidth.

Existing Products

Editing a product updates its details and image. Deleting a product also attempts to remove its uploaded image from Supabase Storage.
