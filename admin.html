PRODUCT MANAGER

Only a Supabase user ID explicitly added to public.admin_users can manage products or upload images.

Admin Sign In

Create the admin user in Supabase Dashboard → Authentication → Users. Then add that user's UUID to public.admin_users using the SQL in the README. This page has no public sign-up form.
